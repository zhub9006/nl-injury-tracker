## How to Contribute

1. **Fork** the repository and create a new branch for your changes.
2. **Update or add** injury data in `SEED-DATA.json` (machine-readable) and/or `INITIAL-DATA.md` (human-readable).
3. **Submit a pull request** with a clear description of what was changed and why.
4. If reporting a new injury, include the **date**, **details**, **rehab timeline**, **return status**, and **source** where available.
5. **Always cross-reference** with official sources: MLB.com, team press releases, and recognized beat reporters.

## Files

| File | Type | Description |
|------|------|-------------|
| `INITIAL-DATA.md` | Human-readable | Comprehensive injury summaries with timelines and sources |
| `SEED-DATA.json` | Machine-readable JSON | Clean initial dataset for apps/scripts |
| `nl-injury-initial-data.json` | Machine-readable JSON | Detailed structured injury database (v2.0.0) |
| `nl-injury-updates.json` | Simplified JSON | Lightweight JSON summary |
| `LATEST-INFO.md` | Human-readable | Current injury updates with quick-reference tables |
| `RESEARCH-UPDATES.md` | Human-readable | Research-based detailed updates with latest sources |
| `DETAILED-UPDATES.md` | Human-readable | Extended career injury timelines |
| `CONTRIBUTING.md` | Documentation | Community contribution guidelines |
