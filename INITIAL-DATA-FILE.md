## How to Contribute

1. **Fork** the repository and create a new branch
2. **Update or add** injury data with date, details, rehab timeline, return status, and source
3. **Submit a PR** with a clear description
4. Always **cross-reference** with official sources: MLB.com, team press releases, recognized beat reporters
5. If reporting a new injury, include: **date**, **mechanism**, **severity**, **rehab timeline**, **return estimate**
