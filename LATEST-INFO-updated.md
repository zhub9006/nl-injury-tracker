## How to Contribute

1. **Fork** the repository and create a new branch for your changes.
2. **Update** `injury-updates.json` (machine-readable) and/or `LATEST-INFO.md` (human-readable).
3. **Submit a pull request** with a clear description of changes and source URLs.
4. Include: **date**, **injury details**, **rehab timeline**, **return status**, and **source URL** for each update.

## Repository Structure

- `injury-updates.json` — Machine-readable JSON database
- `LATEST-INFO.md` — Human-readable markdown summaries
- `README.md` — Project overview and contribution guidelines
