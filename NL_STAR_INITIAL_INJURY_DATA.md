## Data Dictionary & Validation

| Field | Type | Notes |
|-------|------|------|
| `player_id` | string | Unique slug identifier (e.g., `acuna-jr`) |
| `name` | string | Common name for media reference |
| `full_name` | string | Legal name for official records |
| `team` | string | Current team at time of data entry |
| `league` | string | Always `National League` |
| `position` | string | Current listed position(s) |
| `jersey_number` | integer | Jersey number |
| `bats_throws` | string | Batting/throwing handedness, or null |
| `status` | string | `rehabbing`, `active_day_to_day`, `active_healthy`, `on_il` |
| `status_color` | string | `green` = healthy/active; `yellow` = rehab/daily; `red` = on IL/out |
| `current_injury` | object | Primary + secondary injuries with nested fields |
| `rehabilitation_progress` | object | Cleared gates, rehab locations, dates, targets |
| `injury_history` | array | Sorted by date descending with status tracking |
| `manager_quotes` | array | Most recent verified quotes |
| `latest_update` | object | Most current status check with source URLs |
| `career_highlights` | array | Notable achievements and career numbers |

## How to Contribute Updates

1. **Fork** the repository, then create a new branch for your changes.
2. **Update** `NL_STAR_INITIAL_INJURY_DATA.json` (structured, machine-readable) and/or `NL_STAR_INITIAL_INJURY_DATA.md` (this file; human-readable).
3. **Submit a pull request** including:
   - Clear description of what changed and why
   - Source citations (footnoted URLs from recognized outlets)
   - Timestamp of when you last verified information
   - Manager quotes if available from official press conferences
4. Always cross-reference with **at least two** sources (MLB.com, team press releases, ESPN, Yahoo Sports, USA Today, The Athletic, SI.com, beat reporters).
5. Include dates for all injury/rehab milestones.
