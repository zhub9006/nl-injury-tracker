## How to Contribute

1. **Fork** the repository and create a new branch for your changes.
2. **Update** the data files (`injury-updates.json` for machine-readable data, `LATEST-INFO.md` for human-readable summaries).
3. **Submit a pull request** with a clear description of changes and sources.
4. For new injuries, include: **date**, **injury details**, **rehab timeline**, **return status**, and **source URL**.
5. Cross-reference with official sources (MLB.com, team press releases, beat reporters).

## Repository Structure

- `injury-updates.json` — Full machine-readable JSON database of all tracked players' injury histories, current status, and return timelines
- `nl-injury-updates.json` — Compact machine-readable quick-reference JSON
- `LATEST-INFO.md` — Human-readable summaries with quick-reference tables and detailed timelines (this file)
- `README.md` — Project overview and contribution guidelines
